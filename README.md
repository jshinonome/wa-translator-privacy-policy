# WA Translator 隐私权政策

**最后更新日期：2026 年 5 月 11 日**

WA Translator（以下简称"本插件"）是一款浏览器扩展程序，用于在 WhatsApp Web 和 Instagram 网页端提供实时聊天翻译及业务辅助功能。我们非常重视您的隐私，本政策说明本插件如何处理您的数据。

## 1. 数据收集

**本插件不收集、不存储、不传输任何用户个人身份信息。**

本插件不使用任何分析工具、跟踪器或广告 SDK。

## 2. 本地存储的数据

本插件通过浏览器提供的 `chrome.storage.local` API 在您的设备本地保存以下数据：

- 用户偏好设置（目标翻译语言、界面配置等）
- API 密钥（由用户自行配置，用于调用翻译服务）
- 快捷回复模板
- 客户报价记录（产品名称、成本、报价）
- 翻译缓存（已翻译的文本内容）
- 运费计算相关汇率数据

**以上所有数据仅存储在您的本地设备中，不会上传至本插件开发者的任何服务器。**

## 3. 外部网络请求

本插件仅向以下第三方服务发送网络请求：

### 3.1 火山引擎（Volcengine）豆包大模型 API

- **用途：** 发送聊天消息文本以获取翻译结果
- **请求地址：** `https://ark.cn-beijing.volces.com/`
- **传输内容：** 待翻译的消息文本
- **认证方式：** 使用配置的 API 密钥
- **说明：** 本插件不会向该 API 传输您的姓名、电话号码、电子邮箱或其他个人身份信息。翻译请求仅包含消息文本内容。

### 3.2 汇率查询 API

- **用途：** 获取公开外汇汇率（用于运费计算器）
- **请求地址：** `https://open.er-api.com/`
- **传输内容：** 无个人数据，仅请求公开汇率信息
- **触发方式：** 仅在用户主动点击刷新汇率时触发

除上述两个服务外，本插件不向任何其他外部服务器发送网络请求。

## 4. 权限使用说明

| 权限        | 用途                                                                           |
| ----------- | ------------------------------------------------------------------------------ |
| `activeTab` | 在用户点击插件图标时访问当前 WhatsApp Web / Instagram 页面，读取和翻译聊天消息 |
| `storage`   | 在本地保存用户配置、翻译缓存、快捷回复模板和客户报价数据                       |
| `sidePanel` | 在浏览器侧边栏显示翻译面板和业务工具                                           |
| `tabs`      | 检测当前标签页是否为目标页面，并建立面板与内容脚本的通信                       |
| `scripting` | 将内容脚本注入 WhatsApp Web / Instagram 页面以实现翻译功能                     |
| 主机权限    | 访问火山引擎 API 以发送翻译请求                                                |

## 5. 数据共享

本插件不与任何第三方共享用户数据。本插件不出售、不出租、不交易任何用户信息。

## 6. 数据安全

- 所有本地数据通过浏览器内置的存储机制保护
- API 密钥仅存储在用户本地设备中
- 与翻译 API 的通信通过 HTTPS 加密传输

## 7. 儿童隐私

本插件不针对 13 岁以下儿童设计，不会有意收集儿童的个人信息。

## 8. 隐私政策更新

如本隐私政策发生变更，我们将在此页面更新内容并修改顶部的"最后更新日期"。
